# XLS-Аналитика

Локальное веб-приложение для анализа выгрузок XLS/XLSX: приём файла, проверка
структуры, а в следующих историях — предпросмотр, фильтры, графики и экспорт.

## Запуск

```bash
npm.cmd install          # в этой среде npm вызывается как npm.cmd
npm.cmd run dev          # дев-сервер Vite
npm.cmd run build        # tsc --noEmit + vite build → dist/
npm.cmd run test         # vitest run
npm.cmd run lint         # eslint .
```

Требуется Node `^22.22.2 || ^24.15.0 || >=26`.

## Текущий объём (Story 1)

- CAP-1: приём файла XLS/XLSX через выбор или drag-and-drop.
- CAP-2: валидация структуры по обязательному набору колонок B–G, предупреждения
  о грязных конструкциях, блокирующие ошибки.

## Форматы и лимиты

- Только форматы **XLS** и **XLSX**.
- Лимит — **30 000 строк данных суммарно по всем листам файла**; файлы сверх
  лимита отклоняются с явным сообщением.
- Формулы показываются как сохранённые значения, без пересчёта.
- Грязные конструкции (объединённые ячейки, скрытые листы, лишние шапки,
  строки-маркеры) **предупреждают, но не исправляются автоматически**.

## Приватность

Файл обрабатывается полностью в браузере и не покидает устройство: сетевых
запросов с содержимым файла нет.

## Структура

```
src/
  app/        # bootstrap и тема
  domain/     # чистые правила: модель, схема, issue-коды, пайплайн валидации
  adapters/   # File API и SheetJS (тонкие границы побочных эффектов)
  ui/         # React: экраны, компоненты, store, каталог строк ru
tests/        # Vitest: домен и адаптеры
```
