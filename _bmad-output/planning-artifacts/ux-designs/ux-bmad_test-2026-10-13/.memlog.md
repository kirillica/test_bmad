- (decision) Режим Fast path: оба спина с тегами [ASSUMPTION], без креатив-тулз на этапе Discovery
- (decision) Две темы: светлая (data-first, default) и тёмная; переключатель темы в интерфейсе
- (decision) Источники UX: SPEC-xls-analytics (SPEC.md, data-input-rules.md, success-metrics.md), stories.yaml, PRD draft, образец выгрузки с эталонной схемой 9 колонок
- (decision) IA: 3 поверхности — Загрузка (U1), Данные (U2), Анализ (U3) + глобальный хедер (тема, сброс файла); замкнутость: каждый потребный случай контракта покрыт поверхностью
- (decision) U1 Загрузка: drop-zone + выбор файла, инлайн-результат валидации (OK / предупреждения / блокирующие ошибки: формат, лимит 30 000, повреждение, отсутствие обязательных B-G)
- (decision) U2 Данные: вкладки листов, предпросмотр первых строк, чипы типов колонок (число/дата/текст); предупреждения о служебных строках-маркерах — баннер (политика контракта «предупреждать»), не скрывать молча
- (decision) U3 Анализ: панель фильтров (категории Статус/Тип работы/Тип задачи/Исполнитель/Эпик + дата при наличии), переключатель представлений линейный/столбчатый/круговой/таблица, экспорт PNG/PDF/XLSX
- (decision) Состояния: загрузка файла, валидация, блок/предупреждение, пустые результаты фильтра, экспорт, «новый файл» сброс; без сохранения между сессиями (по PRD)
- (decision) Доступность: WCAG 2.2 AA, табличная вьюха как текстовая альтернатива графиков, клавиатурная навигация, контраст обеих тем в токенах DESIGN
- (decision) DESIGN: светлая+тёмная темы (по решению польз.), data-first, системный шрифт [ASSUMPTION], категориальная палитра графиков без потери различимости при отклонениях цветового зрения [ASSUMPTION]
- (decision) Голос: русский, точный, без фанфар — баннер называет проблему конкретно (например, не найдена обязательная колонка Статус), без эмодзи-декора
- (event) Черновики DESIGN.md и EXPERIENCE.md написаны (fast path): IA 3 поверхности, Flow-1+Flow-2, 10 состояний, a11y-пол, палитра двух тем
- (event) Key screens отрисованы: .working/key-upload.html (light + 2 блок-ошибки), key-data.html (light, таблица предпросмотра с чипами типов и служебной строкой), key-analysis.html (dark, фильтры/график/сводная/тост)
